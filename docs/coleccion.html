CONCEPTO
LA MATERIA VIVA

La materia
viva.

El sistema se comporta como un organismo sensible: respira, filtra, se abre, se protege. Cada transformación material equivale a un gesto humano.

Así como el cuerpo se abre para recibir y se cierra para cuidar, el sistema se adapta para equilibrar convivencia y soledad.

Habitar, entonces, no es solo ocupar un espacio, sino una experiencia en la que se coexiste con los otros desde la materia viva del entorno.

COMPONENTES DE METAL / 03

Componentes
del sistema.

02 / 02

Tres piezas de metal sostienen la estructura y permiten instalar HABITARE sin obra.

01 — GUÍA INFERIOR

Guía inferior

Se apoya en el piso y recibe a las piezas cerámicas, que se posicionan, se encastran y se apilan sobre ella.

02 — COMPONENTE TELESCÓPICO

Componente telescópico

Se extiende hasta el techo y se ajusta a la altura de cada ambiente, manteniendo la columna firme.

03 — GUÍA SUPERIOR

Guía superior

Se fija al techo y recibe al componente telescópico, cerrando la estructura en la parte superior.
